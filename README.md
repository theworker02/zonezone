# zonezone

Zone URLs and zone query parts with stable normalization.

**Site:** https://theworker02.github.io/zonezone/

## Install / run

```bash
git clone https://github.com/theworker02/zonezone.git
cd zonezone
node src/cli.js
node --test
```
